# TUS Open

**A free, open-source Anki deck for the Turkish medical specialization exam
(TUS).** Install it and start studying.

[Download the deck](https://github.com/aycibatuhan/tusopen/releases) ·
[What is Anki?](docs/anki-ve-aralikli-tekrar.md) (Turkish) ·
[About](docs/hakkinda.md) (Turkish)

## What's inside

- **15,557 cards** (10,117 notes): clinical vignettes, condition summaries,
  fact cards, image-occlusion anatomy
- **333 illness scripts** and **5,736 fact cards**, verified against current
  guidelines (ESC 2021-23, GINA/GOLD 2024, ADA 2025, ACG 2024, NCCN 2025, TG18)
- **60 interactive clinical cases** plus an oral-exam mode ([simulator](site/))
- **Frequency tags**: how many past TUS sittings asked each topic, derived from
  a tagged 13-year archive of 4,253 questions
- **9 walkthroughs**: own-words reasoning on real past questions

All content is `draft` status; human review is ongoing.

## Install (2 minutes)

1. Install Anki (free): [apps.ankiweb.net](https://apps.ankiweb.net)
2. Download `tusopen.apkg` from the
   [Releases](https://github.com/aycibatuhan/tusopen/releases) page
3. Double-click the file. Done.

To receive future updates automatically, install the
[add-on](addon/tusopen_guncelle/README.md): it announces new releases and
imports them while preserving your scheduling.
